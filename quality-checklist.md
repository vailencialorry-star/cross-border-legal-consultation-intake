# Quality Checklist

Complete applicable checks before delivery.

## A. Source coverage

- [ ] Entire source document was read; no truncation remains.
- [ ] Every numbered question and material bullet appears in the coverage ledger.
- [ ] Duplicates were merged only after retaining all original locations.
- [ ] Every final issue has a stable ID.
- [ ] The final report contains a source-to-section coverage index.

## B. Legal architecture

- [ ] Contract obligations and proprietary title are separate.
- [ ] Platform, agent, seller, warehouse, PSP, exporter and importer roles are explicit.
- [ ] P2P, consignment and buyout are analyzed separately.
- [ ] Taxable supply and physical import/export are separate.
- [ ] Personal-use, retail e-commerce and commercial import routes are separate.
- [ ] Statutory AML duties and prudent controls are separate.
- [ ] Platform suspension, PSP freeze, warehouse lien and official seizure are separate.

## C. Research quality

- [ ] Material conclusions cite official or first-party sources.
- [ ] Every source was opened and read.
- [ ] Provision numbers and effective/update dates were checked.
- [ ] Foreign-language translations are labelled correctly.
- [ ] Treaty status, reservations, protocols and MLI modifications were checked when relevant.
- [ ] Local practice is not described as a statutory rule.
- [ ] Unresolved issues name the exact required local opinion, ruling, licence or confirmation.

## D. Actionability

- [ ] Every material issue has a risk level and operational action.
- [ ] Launchable/conditional/defer decisions include reasons and conditions.
- [ ] Product prohibitions are explicit.
- [ ] Required agreements and clauses are identified.
- [ ] Required KYC/KYB, customs, tax, payment and source documents are identified.
- [ ] Manual-review, escalation, report and record-retention steps are identified.
- [ ] A standard launch path can be converted into product requirements.

## E. Citations and writing

- [ ] Report moves from overall conclusions to supporting details.
- [ ] Analysis uses paragraphs; tables organize comparisons.
- [ ] Each sentence makes one main proposition where possible.
- [ ] Numeric citations are used consistently.
- [ ] Every citation has one matching reference definition.
- [ ] Reference titles are descriptive and URLs are official where available.
- [ ] Preliminary-opinion and jurisdiction limitations are prominent.

## F. File validation

- [ ] Markdown output exists, is non-empty and contains all required sections.
- [ ] Word output, if created, opens and contains the entire text.
- [ ] Chinese text and tables render correctly in several inspected pages.
- [ ] Contents/heading levels are usable.
- [ ] No unintended client identifiers or prior matter facts remain in a reusable template.
- [ ] Every created or updated user-facing file is attached with its verified absolute path.
